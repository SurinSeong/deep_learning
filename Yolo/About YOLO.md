# Yolo

## 객체 검출

[객체 검출](https://rubber-tree.tistory.com/119)

- 정지 영상 또는 동영상에서의 객체 검출
    - 영상처리 및 컴퓨터 비전 분야에서 많이 활용되는 기술 중 하나

- 객체 검출 알고리즘
    - 주요 객체를 탐지하고 해당 객체를 중심으로 바운딩 박스를 표시하여 구분한다.
    - 주요 활용분야 : 차량 감지/추적, 감시 시스템, 얼굴 인식, 이미지 분류, 비디오 인식, 음성 인식 등과 같은 다양한 응용 분야에서 활용되는 주요 머신러닝 도구 >> CNN 알고리즘이 활용된다.
